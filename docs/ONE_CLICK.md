# 终端维护入口（兼容保留）

日常操作请使用桌面的 **小红书采集助手.app**，详见 [桌面 App 操作说明](DESKTOP_APP.md)。下面的 1–8 菜单作为维护备用保留，不是新版 App 的操作步骤。

本说明与 **0.5.0** 配套。不能仅凭安装软件或阅读本说明判断手机连接和页面校准已经通过，必须执行设备检查和实机验收。

需要终端维护时，可打开 **启动小红书采集.command**。项目目录里也有同名入口。终端会打开中文菜单，首次打开菜单不会操作手机。不要在 App 采集时再次启动终端采集。

| 选择 | 用途 | 需要填写 |
| --- | --- | --- |
| **1** | 采集当前图文笔记 | 无；先在云手机打开笔记详情 |
| **2** | 自动搜索、进入图文笔记并保存 | 关键词、目标条数；回车默认 10 条，范围 1–500 |
| **3** | 恢复中断或暂停的任务 | 选择原任务编号 |
| **4** | 查看已有任务并导出 | 选择任务编号；手机离线也能用 |
| **5** | 检查数据库和手机连接 | 无；不创建采集任务、不输入文字 |
| **6** | 多个关键词自动依次采集 | 每行一个关键词，空行结束；最多 20 个词，每词默认 10 条、范围 1–500 |
| **7** | 恢复已有批次 | 选择原批次编号 |
| **8** | 查看批次并导出汇总 | 选择批次编号；手机离线也能用 |
| **0** | 退出菜单 | 无 |

选择采集、恢复或检查功能后，程序准备本项目的持久数据库，必要时启动已配置的连接服务，并检查指定的 `lab01` 手机。无需输入 serial、数据库密码或命令，也无需 Codex 或大模型密钥。启动器不负责首次采购和安装云手机；当前 Mac 已完成原有接入配置。

新任务的详情预算为 `max(100, 3 × 目标)`，列表滚动预算为 `max(50, 向上取整(详情预算 ÷ 2))`；每词目标 500 时分别为 **1,500／750**。旧任务的目标、预算及已用次数不随升级改变。每词目标指字段达标记录，结果仍需人工核验；运行继续保留至少 3 秒主动操作间隔、冷却和无新增停止。

## 结果和暂停

运行期间保持 Mac 开机、网络畅通及采集窗口打开。按 **Ctrl+C** 请求安全暂停，等待当前动作结束和结果状态出现后再关闭窗口。关机、睡眠和强制关闭终端会中断进程；重新双击入口，选择 **3** 恢复原任务。恢复保留任务 ID、已提交记录、预算和冷却，重新搜索并核对笔记，不依赖原滚动位置。

采集结束或正常暂停后，程序显示保存条数、合格观察数、人工已确认身份数以及停止原因，并自动导出到：

```text
var/exports/任务ID/本次导出时间/
    notes.csv
    notes.jsonl
```

多关键词批次导出到 `var/exports/batches/批次ID/本次导出时间/`，包含同一次数据库读取生成的 `notes.csv`、`notes.jsonl` 和关键词/任务映射 `summary.json`。如果存在 `INCOMPLETE.txt`，表示这次导出未完成，应从菜单 8 重试导出。恢复批次请选择 **7**；不必分别恢复每个子任务。完整步骤见 [单机批量采集](BATCH_COLLECTION.md)。

正常交互运行会自动打开结果文件夹。每次导出使用新的目录，不覆盖上次导出。日志位于 `var/launcher/本次启动时间/`；截图与 UI 树仍保存在 `var/evidence/`，导出记录包含关联信息。

“采集结束，待人工核验”表示程序保存了记录。人工核对和不同笔记身份确认仍单独进行，启动器不会自动提交人工审阅，也不会将已采集数量当作 30 篇验收通过。

## 提示与恢复

- **手机无法连接**：确认阿里云实例已开机、网络正常、ADB 可用。启动器只对已配置连接做有限重连。
- **自动化读取或诊断失败**：查看具体诊断；手机连接正常时不会据此宣称手机离线。
- **页面读取次数已用完**：在桌面 App 对原任务选择“检查并继续”。检查连接、自动化与当前页通过后追加 3 次读取尝试；重复请求不叠加，普通菜单恢复不自动加额度。详情、列表和断线恢复预算、累计失败及成果不清零。
- **手机正被另一进程使用**：返回原采集窗口查看进度或暂停；不能双开控制同一台设备。
- **登录、验证码或其他需要人工处理的页面**：在云手机正常处理。启动器不会自动确认已处理或清除限制；处理完成后使用原任务的 `resume --acknowledge`，程序仍会重新检查页面。
- **版本不匹配或未知页面**：保留证据并进行页面校准；启动器不会跳过检查。
- **数据库或导出失败**：查看启动日志与菜单 4 的任务状态。已提交成果保留；导出可重试。

## 本机配置与维护

入口脚本从自身位置定位项目，支持路径含中文和空格；桌面快捷方式链接到项目入口。项目移动后，需要重建桌面快捷方式并更新连接服务的路径。

配置继续读取 `config.local.toml`。`lab01` 的本地 ADB serial 来自私有接入记录 `var/connection/mobile-lab01.json` 的 `adb.local_serial`，通过该设备配置指定的环境变量传入子进程，启动器不默认使用第一台已连接手机。当前启动器服务于这台 Mac 的单设备部署；多设备/多主机调度属于后续阶段。

终端与 App 共用连接模块，`auto_connection.authorization_mode` 支持 `open` 和 `prefix_list`；缺省沿用原白名单模式。开放模式需要先完成云端规则配置，日常连接不探测公网 IP、不操作白名单、不读取 RAM 凭据或钥匙串。两种模式都保留自动连接开关、系统路线优先和有限物理路线回退，详见 [自动连接操作说明](AUTO_CONNECTION.md)。

手机连接服务的登录自动启动配置为 `~/Library/LaunchAgents/com.codex.mobile-lab01-adb-relay.plist`，仅本机保存，不能提交到仓库。已有服务不会被强制重启；缺失时才加载此配置。登录后自动启动依赖此项目路径和 Python 环境保持有效。

开发者可执行以下无采集检查：

```sh
.venv/bin/python scripts/launcher.py --check
```

该命令启动/检查数据库、检查手机及自动化服务，不创建任务、不搜索、不替换输入框文字。它不替代搜索采集和 30 篇人工验收。
