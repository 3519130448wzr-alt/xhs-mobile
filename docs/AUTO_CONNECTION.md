# 本机自动连接操作说明

适用于当前 Mac 的“小红书采集助手”**0.4.0**。程序继续在本机运行，连接现有 Android 云手机，不需要新增服务器、Agent 或大模型密钥。

## 两种连接方式

“自动识别网络并连接云手机”开关与“连接方式”分别设置。开启自动连接后，两种方式都会复用健康连接，断线时尝试系统路线及可用物理网络。

| 方式 | 云端前提 | 日常连接行为 |
| --- | --- | --- |
| **开放连接 `open`** | 当前云手机的 TCP 5555 入站规则允许所有 IPv4 来源 `0.0.0.0/0` | 不探测公网 IP、不维护白名单，不访问 RAM 凭据或钥匙串；界面显示“开放连接，无需地址授权” |
| **自动白名单 `prefix_list`** | 已关联专用前缀列表，并配置受限 RAM 凭据 | 按实际出口更新单地址白名单，核验手机连接后清理旧地址 |

未指定连接方式的旧配置继续使用 `prefix_list`。切换到开放模式保留原白名单资料供回退，不删除凭据、云规则或历史数据。

**本说明只描述软件行为，不代表使用者的云端规则已经配置或实机连接已经通过。** 连接成功必须由指定 serial 的 ADB 状态和只读 shell 往返确认。

## 日常使用

1. 双击桌面 App。它自动准备本机数据库和手机连接，不会开始或恢复采集。
2. 填写关键词并点击“开始采集”。程序确认自动化服务与小红书版本后执行。
3. VPN 路线无法连接时，程序仅让手机连接尝试当前 Wi-Fi 或有线网络直连，不关闭 VPN、不改其他应用的路由。
4. 普通断线会在当前任务的持久化预算内恢复。验证码、登录失效、未知页面和限频提示仍需要原有处理流程。
5. 关闭窗口后任务继续；主动退出 App 会安全暂停。重开 App 只连接手机，不自动续跑历史任务。

网络需要有至少一条可用的手机 ADB 路线，云手机需要开机且 ADB 授权有效。只有自动白名单模式另外需要访问阿里云授权接口；开放模式不依赖该接口。网络封锁、手机停机或 ADB 授权失效会给出具体提示，不会一直显示正在连接。

## 开放连接：首次配置

1. 保存当前云手机安全组规则，供回退核对。以下使用 `<SECURITY_GROUP_ID>` 代表使用者自己的安全组。
2. 在该安全组新增入站规则：**允许、优先级 1、自定义 TCP、来源 `0.0.0.0/0`、目标端口 `5555/5555`**。保留已有供应商内网、固定地址和前缀列表规则。
3. 保存后重新读取并核对规则确已生效，再到 App“设备连接 → 自动连接设置”选择“开放连接”，保持自动连接开启，点击“保存并检查连接”。无需录入 RAM 或钥匙串凭据。
4. 确认 App 显示“开放连接，无需地址授权”且手机已连接，再按需要开始采集。保存设置和连接成功均不会自动启动任务。

公网 ADB 映射使用 `<CLOUD_PHONE_HOST>:<MAPPED_PORT>`，手机内部 ADB 端口为 `5555`，本机入口可配置为类似 `127.0.0.1:6100`。安全组使用手机内部端口 5555，不能误填公网映射端口。

开放模式只管理本机连接路线；它不会通过 App 自动新增或删除安全组规则。崩溃后仅恢复本地路线日志，不读取或处理旧白名单更新日志。旧授权资料缺失、钥匙串拒绝访问或公网 IP 查询不可用，不应阻止开放模式建立手机连接。

## 自动白名单：原配置与回退说明

以下仅适用于 `prefix_list` 模式。已经完成配置的用户可以继续使用原资源，无需重新创建。

### 云端准备

在现有云账号的同一区域创建专用 IPv4 前缀列表，名称 `xhs-mobile-lab01`，最大容量 **2**，初始不添加条目。

在当前云手机安全组新增一条允许规则：来源为该前缀列表，协议 TCP，目的端口 **5555/5555**。这里只设置手机内部 ADB 端口；公网映射端口单独保存在设备接入记录中。

首次关联后人工核对：该名单只关联当前安全组，且只被预期的 TCP 5555 规则引用。运行时受限权限能读取关联的资源，不能证明同一安全组中每条规则的端口，因此这项检查不能省略。保留供应商内网规则；新的自动授权路线实测成功前保留原固定公网地址规则以便回退。

创建一个项目专用 RAM 用户，使用自定义策略，仅授予以下三项操作，Resource 填入这份名单的完整 ARN：

```json
{
  "Version": "1",
  "Statement": [{
    "Effect": "Allow",
    "Action": [
      "ecs:DescribePrefixListAttributes",
      "ecs:DescribePrefixListAssociations",
      "ecs:ModifyPrefixList"
    ],
    "Resource": ["acs:ecs:REGION:ACCOUNT_ID:prefixlist/PREFIX_LIST_ID"]
  }]
}
```

不要给此用户添加管理员策略或通配资源写权限。专用用户创建 AccessKey 后，由用户直接录入本机 App，不需要发给 Agent，也不要写进终端、聊天、项目配置或环境变量。

建议专用用户和策略采用项目独立名称，例如 `xhs-mobile-device01` 与 `XHSMobilePrefixListAccess`。创建成功不代表授权、名单关联或实际 ADB 路线已经验证。

此前 0.3.1 的首次授权记录已验证 App 更新名单、失败路线回退及重新打开后的自动重连。这是白名单模式的历史验证，不作为 0.4.0 开放连接已经部署或实机通过的证明。白名单模式日常换 IP 也不需要用户逐个登录、录入密钥或确认地址。

### App 内设置

打开“设备连接 → 自动连接设置”，开启“自动识别网络并连接云手机”，选择“自动白名单”。核对区域、账号、名单、安全组和名单名称，录入专用 AccessKey，保存至 macOS 登录钥匙串。普通连接记录只保存资源标识和钥匙串引用。随后主动执行连接检查。

“保存并检查连接”不会开始或恢复采集。若现有 ADB 健康，程序会直接复用；此时显示已连接不能证明新密钥或自动白名单已验证。维护人员验收时核对专用名单中的实际出口 `/32`、连接事务日志完成状态及 ADB/shell 往返成功；额外网络切换测试不属于用户日常启动步骤。原固定规则在验证成功前保留。

App 更新签名后，macOS 还可能重新请求“文稿”文件夹访问权限。后台等待授权时请在系统弹窗中点“允许”，然后检查连接；不需要开启完全磁盘访问权限。

自动白名单模式在更新签名、首次使用、钥匙串锁定或拒绝访问时，macOS 可能要求一次正常钥匙串授权。普通换网不应重复录入密钥。开放模式不访问钥匙串，但系统对“文稿”目录的访问权限仍独立适用。

## 有限重连与白名单更新

两种模式均先复用健康连接，再按系统路线、可用物理接口的顺序尝试，最多三个候选、总截止时间 120 秒，所有等待可取消。连接成功以指定设备的 ADB 状态和只读 shell 往返为准；TCP 连通不算成功。失败或取消恢复之前的本机路线，转发器只监听本机回环地址，不关闭 VPN 或修改全局路由。

只有自动白名单模式还执行以下步骤：

- 公网地址探测与手机连接使用相同候选出口；浏览器显示的 IP 不作为手机出口的证据。
- 仅加入单个公网 IPv4 `/32`，验证连接成功前保留旧地址。
- 成功后清理旧地址；失败回退候选地址和路线。云 API 结果不明确时先读取核对，不反复盲目追加。
- 更新日志保存在私有连接目录，进程意外退出后先核对日志和云端名单。

采集进程持有设备锁并自行恢复；桌面三秒进度刷新只读取数据库，不争抢手机。每个任务默认累计最多三个连接候选尝试，每次先保存预算；成功、暂停和重新启动不清零。预算耗尽后展示已有结果，不通过“检查并继续”补充断线恢复预算。

每词目标默认为 10，允许 1–500 条，批次最多 20 个关键词。新任务目标 500 时，详情／列表预算为 1,500／750；旧任务预算保持原样。目标数量与连接恢复次数分别计算，详情见 [批量采集说明](BATCH_COLLECTION.md)。

## 常见提示

| 提示 | 操作 |
| --- | --- |
| 请完成自动连接授权 | 仅自动白名单模式需要检查钥匙串和专用凭据；开放模式无需此步骤 |
| 连接授权权限不足 | 自动白名单模式核对三项 RAM 操作、名单 ARN 及关联的安全组；ADB 授权失败则处理手机本身的 ADB 绑定 |
| 本次连接已超时 | 保留已有结果；检查当前网络、实例开机及 ADB 映射后重试 |
| 名单或关联不匹配 | 仅自动白名单模式核对名单与关联；开放模式不读取这些资料 |
| 设备正在使用 | 等待原任务停止，不启动第二个控制进程 |
| 自动重连次数已用完 | 查看和导出原任务结果，重连预算不会重置 |
| 已连接，版本待适配 | 连接正常，需要更新真实页面适配，不能直接继续采集 |
| 手机已连接，但自动化读取／诊断失败 | 查看诊断详情并重新检查；缺少诊断输出不等于手机离线 |
| 页面读取次数已用完 | 对原任务选择“检查并继续”；检查通过后追加 3 次读取尝试，累计失败及其他预算保留 |

“打开云手机”始终使用现有阿里云控制台地址。打开网页不等于故障已解决，处理后需要重新检查。

“检查并继续”针对已耗尽的页面读取次数，必须持有设备锁并通过连接、自动化服务和当前页面核验，相同请求不重复追加。登录、验证码及未知页面仍需先人工处理并明确确认，冷却未到期不能跳过；该入口不会恢复详情、列表或连接预算。打开 App、刷新或普通重启不会自动补充读取额度。

## 安装、回退与验收

安装更新会保留本项目连接记录及转发服务的备份，保持原本地 serial。转发器继续只监听本机回环地址。旧终端入口调用同一连接模块；只有白名单模式调用原生授权助手。

回退到自动白名单时，在设置中选择 `prefix_list` 并使用保留的资源资料与凭据。客户端模式切换不会撤销云端已经开放的 `0.0.0.0/0` 规则；如需恢复原云端访问范围，须按保存的规则另行调整，并重新验证原路线。关闭自动连接也不会自动修改任何云规则。不要删除数据库、采集证据或任务状态。

工程测试通过不代表实机换网验收通过。实机验收应覆盖两个不同公网出口、VPN 路线变化、运行中断线、暂停和退出、导出一致性，并从普通终端或桌面独立启动。采集由实验室启动，测试样本不计入真实成果。
