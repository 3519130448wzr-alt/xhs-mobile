# 第一阶段验收

本阶段目标是一台实际 Android 云手机中的小红书图文笔记采集程序，可独立执行关键词搜索、遍历、详情提取、持久化和异常恢复。

本文定义 3 个关键词、不同笔记身份和恢复测试要求。离线夹具、解析器单元测试、系统级设备接入与实机结果必须分别记录；任何 synthetic 数据都不能用于下面的 30 篇验收。公开仓库不包含实验室私有验收记录。

## 1. 通过条件

- 实验室选择 3 个不同的实际关键词，每个关键词人工核验 10 篇图文笔记，跨关键词合计 30 篇不同笔记。
- 所有入选笔记都来自实际 Android 手机上的小红书 App。浏览器移动仿真、网页替代、从笔记配图中识别的文字和生成数据不计入。
- 每篇入选笔记的正文完整、作者可读；标题可读，或确实没有显示标题并保留证据。仅没有识别出标题不能认定为“未显示标题”。
- 每篇入选记录都有对应真实截图、UI 树、采集时间及任务来源，并完成记录到证据的人工核对。
- 程序在普通终端独立启动并完成搜索、遍历、保存；正常执行不依赖 Agent、云端大模型或大模型密钥。
- 实机验证暂停／恢复和设备断开后的恢复；离线测试验证事务、互斥、重试预算及冷却等故障分支。

不另设未经约定的连续运行时长或成功率门槛。未达到条件时报告已完成部分和具体缺口。

## 2. 字段与真实性

| 字段 | 验收要求 |
| --- | --- |
| `title` | 保存页面标题原文；页面确实未显示标题时允许 `not_displayed`，需人工核对。 |
| `body` | 保存完整正文原文。截断、未展开、未读完或重复拼接的正文不合格。 |
| `author` | 保存详情页实际展示的作者。缺失或不能确认时不合格。 |
| `published_at` | 可选，保存实际显示时间；“昨天”等文本不能补造为未经证实的精确时间。 |
| `likes` / `favorites` / `comments` | 可选，保存显示原值。`1.2万` 等近似值保留原文并标记 `approximate`，不能当作精确计数。 |
| `tags` | 可选，保留页面实际可读标签。 |
| `note_url` | 可选，仅保存正常页面操作实际取得的链接；不能根据正文拼造平台链接。 |

不读取图片中的内容，不采集评论正文。可选字段读不到时记录缺失状态与原因，不能填 `0`、猜测或由模型补齐。UI 是否可读必须用当前 App 版本和实际手机验证。

可选的本地 OCR 仅用于已校准的页面文本区域，需保存 OCR 来源、区域和置信度，再人工核对截图；不能扩展为读取笔记配图。低质量结果不通过基础字段验收，笔记 ID 不能依靠 OCR 建立可信身份。

模型的 `eligible` 只表示基础字段满足程序质量门槛，不表示人工验收通过，也不证明笔记身份唯一。

## 3. 笔记身份与人工审阅

- 优先使用有来源证据的可信平台笔记 ID。审阅时采用 `note:<id>` 身份，人工身份参数不能覆盖它。
- 没有可信笔记 ID 时，由审阅人对真实证据核验后指定全局人工身份键。该键只是实验内部标识，不是补造的平台 ID。
- 同一篇笔记在不同任务、关键词或重复运行中出现，必须复用同一个人工身份键；不能为每条观察记录新建身份键来增加数量。
- 文本指纹仅辅助发现候选重复。作者相同、正文相同或卡片位置相同，都不能独立证明笔记相同；正文修改也不一定代表新笔记。
- 缺少基础字段的记录不能通过 `accept` 补救。程序不再自动判断正文完整性；审阅人确认不完整时应拒绝并补采，不能把“基础字段可读”当作人工验收通过。
- 30 篇记录全部经过人工核对，审阅结论应能追溯到审阅人、记录及身份。存在疑问的记录暂不计入。

## 4. 执行流程

完整环境准备见 [云手机接入](CLOUD_PHONE_SETUP.md)。以下命令在项目目录执行，默认读取 `config.local.toml`。示例中的设备、关键词、观察记录 ID 和任务 ID 必须替换为实际值。全局 `--config` 放在子命令之前。

```sh
uv run xhs-mobile --config config.local.toml doctor --device lab01
uv run xhs-mobile --config config.local.toml snapshot --device lab01 --label home
```

完成真实页面规则校准后，先由实验室打开一篇图文笔记检查当前详情采集，再分别运行 3 个关键词任务：

```sh
uv run xhs-mobile collect-current --device lab01
uv run xhs-mobile run --device lab01 --keyword '实际关键词甲' --limit 10
uv run xhs-mobile run --device lab01 --keyword '实际关键词乙' --limit 10
uv run xhs-mobile run --device lab01 --keyword '实际关键词丙' --limit 10
uv run xhs-mobile status
```

`--limit 10` 是程序任务目标，不代表已经产生 10 篇人工验收通过且与其他关键词不同的笔记。记录缺失、审阅拒绝或身份重复时，需按状态补采；不能仅凭进程正常退出宣告达标。

审阅人逐条打开记录对应证据，核对正文完整性、作者、标题、可选字段与身份，再提交结论：

```sh
uv run xhs-mobile review --observation OBSERVATION_ID --reviewer '审阅人姓名' --verdict accept
uv run xhs-mobile review --observation OBSERVATION_ID --reviewer '审阅人姓名' --verdict accept --identity manual-note-0001
uv run xhs-mobile review --observation OBSERVATION_ID --reviewer '审阅人姓名' --verdict reject
```

第一个示例用于存在可信笔记 ID 的记录，第二个示例用于缺少可信 ID 且已经人工确认身份的记录，两者按记录情况选择。人工身份键需跨任务统一维护。

```sh
uv run xhs-mobile acceptance --tasks TASK_A --tasks TASK_B --tasks TASK_C
uv run xhs-mobile export --format jsonl --output results.jsonl
uv run xhs-mobile export --format csv --output results.csv
```

验收报告须能核对每关键词入选数量和跨关键词身份重复情况。没有满足全部条件时保留未通过结果，不修改身份键或字段来凑数。

## 5. 测试与故障场景

| 场景 | 检查方式 | 预期结果 |
| --- | --- | --- |
| 真实搜索与详情 | 实验室在一台云手机上运行关键词任务，逐条核对截图／UI 树与导出。 | 字段源于真实页面，可追溯；不合格记录不计入人工验收。 |
| 正常暂停／恢复 | 对实际任务执行 `pause --task TASK_ID`，确认已停后执行 `resume --task TASK_ID`。 | 保存进度，恢复同一任务；重新搜索与扫描，不使用旧卡片位置继续点击。 |
| 设备断开 | 实验室通过正常连接方式断开再恢复连接。 | 有限重试或可恢复停止，不静默丢失已提交数据，不无限操作。 |
| 同设备互斥 | 同一控制主机、同一状态目录同时启动两个操作进程。 | 只有一个获得设备操作权；另一个明确报告占用。 |
| 提交边界崩溃 | 离线故障注入分别覆盖提取后、事务提交前和提交后。 | 已提交记录与进度一致；重启不会因半次提交虚增数量。 |
| 搜索结果重排 | synthetic 测试中改变卡片顺序，随后恢复任务。 | 不把卡片索引、坐标或滚动位置当作跨运行身份。 |
| 重复身份 | 同 ID 重复出现、不同 ID 具有相同正文、无 ID 相似正文分别测试。 | 可信同 ID 幂等；不同 ID 不合并；不确定身份不伪装成已确认唯一。 |
| 限制／验证／登录失效 | 使用明确标注 synthetic 的异常页面夹具，不主动触发平台限制。 | 停止、冷却或等待人工处理；不破解验证，不切换身份绕过限制。 |
| 冷却与预算恢复 | 在冷却或重试预算接近上限时终止并重启。 | 冷却、操作／访问／断连预算及连续异常状态持续生效；成功读取可清除连续读取失败，历史累计读取失败不再锁定任务。 |
| 页面规则过期 | 解析不符合规则的 UI 树或页面。 | 保存证据并明确报告未知页面／校准问题，不盲目持续点击。 |
| 导出 | 核对数据库中的记录与 JSONL／CSV。 | 原始显示值、缺失状态、身份、来源和审阅结果可核验。 |

开发检查使用 `uv run ruff check .` 和 `uv run pytest`。PostgreSQL 集成测试必须通过 `TEST_DATABASE_URL` 显式指向隔离测试库；未配置或跳过的集成测试不能报告为通过。

## 6. 交付记录

保留真实设备／App／页面规则版本、3 个关键词、任务 ID、审阅人、30 篇入选记录和证据位置、验收命令结果、异常恢复记录、导出文件及已知限制。账号密钥与 ADB 凭证不进入报告。

当前基线：云手机基础接入、小红书登录、中文输入、页面校准及单关键词自动搜索采集均已验证；用户本次验收确认已作为任务级声明留档。原计划的 3 个关键词、逐记录全局身份以及实机暂停/断连恢复记录尚需补齐，后续按实际证据逐项更新。任务级确认不自动为未指定的观察记录生成身份或审阅结论。
