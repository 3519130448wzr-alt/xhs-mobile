# 小红书采集助手

本说明适用于 **0.5.0**。文档与软件测试通过不表示使用者的设备已经完成页面校准或真实数据验收，具体要求见 [验收清单](ACCEPTANCE.md)。

日常双击桌面 **小红书采集助手.app**。这是当前 Mac 的原生应用，复用项目中已经配置的 Python、持久数据库和云手机连接，正常运行不需要 Codex、终端菜单或大模型密钥。

首次打开时，macOS 可能询问是否允许 App 访问“文稿”文件夹。项目位于该文件夹内，需要由你在系统提示中选择允许，后台才能读取运行环境和已有数据。此时界面仍可打开，但后台可能处于等待状态；不需要开启“完全磁盘访问权限”。

## 三个页面

| 页面 | 用途 |
| --- | --- |
| 开始采集 | 输入一个或多个关键词、设置每词目标；也可采集手机当前打开的笔记 |
| 任务与结果 | 查看进度、暂停／继续、预览原文及来源证据、导出结果 |
| 设备连接 | 查看本机服务与手机状态、检查并连接、打开云手机处理问题 |

旧菜单的单关键词与多关键词合并成同一表单；原来的任务恢复、批次恢复、查看和导出合并到任务列表。批次下的各个关键词显示在批次明细中，避免重复列出。

## 开始一次采集

1. 在“开始采集”输入关键词，每行一个；可直接粘贴多行。
2. 设置每个关键词的目标，默认 **10** 条，允许 **1–500** 条。表单展示关键词数量、合并的重复项及总目标，最多 **20** 个不同关键词。
3. 点击开始。程序先检查运行条件，通过后依次采集；检查失败时填写内容保留。
4. 在“任务与结果”查看当前关键词、已保存记录和基础字段可读记录。

如果只采集手机当前笔记，先点击“打开云手机”，人工打开一篇图文详情，再使用“采集当前笔记”入口。这不要求填写关键词。

打开 App 会异步准备连接，但不会开始或恢复采集，也不会自动确认登录／验证码问题已经解决。首次请在设备页完成[自动连接设置](AUTO_CONNECTION.md)。

标题、作者、正文可读就计入“基础字段可读记录”；有明确页面证据证明未展示标题时保留例外。正文完整性由人工核对，不再因正文超出一屏或出现普通省略号而排除。目标按此数量计算；500 条上限不保证每个关键词都能得到 500 条，也不等于 500 篇已人工确认的不同笔记。新任务根据目标生成有限预算：详情访问为 `max(100, 3 × 目标)`，列表滚动为 `max(50, 向上取整(详情预算 ÷ 2))`。目标 500 时分别为 **1,500 次详情、750 次列表滚动**。历史任务继续使用原目标与已保存预算，升级及恢复不会重算；最小 3 秒主动操作间隔、限频冷却与连续 10 次页面无进展提醒继续生效。

## 暂停、关闭和退出

- **暂停**：请求安全暂停，界面先显示正在暂停；当前操作和保存收尾后才显示已暂停。
- **关闭红色窗口按钮**：App 保留在 Dock，采集继续。点击 Dock 图标重新打开原窗口。
- **退出 App／⌘Q**：等待采集安全暂停后退出。等待期间可取消退出，但已经发出的暂停请求不会自动撤销。
- **意外退出**：桌面控制管道关闭会请求采集停止。重新打开后核对数据库及进程状态；不会自动再发送开始指令。

后台运行仍需要 Mac 开机、保持唤醒并联网；关闭窗口不等于可以让电脑关机或睡眠。恢复继续使用原任务、已保存记录、运行预算和冷却状态。

读取不再受任务终身累计失败次数限制。程序分别记录连续读取失败和执行页面操作后连续无进展；任一连续计数达到 **10 次**时安全暂停，提示人工检查。成功读取或确认页面进展会清除对应连续计数，累计历史失败仍保留诊断。检查后主动选择 **“检查并继续”**，不需要补充读取额度；其他详情、列表、断线恢复预算不重置。旧版被读取额度暂停的任务同样可检查后继续。打开 App、刷新或网络恢复都不会自行恢复采集。需要人工处理时使用“处理后检查并继续”，仍须完成原有页面核验；冷却未到期不能跳过。

## 结果与导出

任务详情默认展开已保存正文，长正文可手动收起。缺失提示分别指出标题、作者或正文；“正文完整性未自动判断”表示需要人工核对，并不等于已确认不完整。原始截图和 UI 树可直接打开。查看任务或预览记录不会操作手机，也不会自动导出。

页面时间原样显示并导出，不推算年份或具体日期；“编辑于”的原文标为编辑时间。平台话题只展示已确认的话题组件或行为结果，同篇相同话题合并显示；无法确认时显示“平台话题未能识别”。正文里的普通 `#文字` 不会自动变成平台话题。

每条记录单独显示笔记身份状态。只有可靠标准笔记 ID 才参与自动去重；取不到 ID 时仍保存可读成果，但标为“身份未核验”，因此可能重复。重启后可能仍需进入详情确认 ID，不用标题、正文或旧坐标猜测身份。

正常采集结束、部分完成或暂停时会尝试自动导出。使用“打开结果文件夹”查看 CSV／JSONL；也可点击导出重新生成文件。文件采用新目录，保留之前版本。退出 App 时不必等待导出，数据库中的结果仍可在下次打开后导出。

导出失败只表示文件生成失败，不表示数据库成果丢失。使用“重新导出”，无需重新采集。出现 `INCOMPLETE.txt` 的导出目录不能当作完整结果。

界面分别展示 **已保存记录、基础字段可读记录、可靠 ID 不同笔记、人工确认不同笔记**。可靠 ID 数量按当前任务或批次内已保存的不同 ID 计算，未核验身份的记录不会计入该数量。“采集结束，待人工核验”不代表所有记录已被人工验收；相同文字也不能自动证明是同一篇笔记。

## 手机故障处理

固定云手机入口：[阿里云无影控制台](https://wya.wuying.aliyun.com/instanceLayouts)。App 使用系统默认浏览器，登录和手机内提示由实验室人工处理。

浏览器中能看到手机画面，不代表本机的采集连接已经建立。App 检查的是配置设备的 ADB 连接、自动化服务和小红书版本；如果画面可用但连接失败，应核对实例是否正常运行、ADB 接入设置和本机网络。连接重试最多三次，显示当前次数，结束后可以重新检查；不会一直停留在“正在检查”。

设备页的“自动连接设置”区分 **开放连接** 与 **自动白名单**。开放连接用于已在云端允许所有 IPv4 来源的手机，显示“开放连接，无需地址授权”，不探测公网 IP、不维护白名单，也不访问 RAM 凭据或钥匙串。自动白名单模式继续使用原有专用名单授权流程，供原配置及回退使用；旧配置未指定模式时沿用自动白名单。

开启自动连接后，空闲时切换 Wi-Fi 或 VPN 路线会触发一次有限重连。两种模式均优先复用健康连接；需要重连时先尝试系统路线，再尝试可用物理网络，最多三个候选、总计 120 秒。仅手机采集连接可能改走直连，其他应用保持原来的网络设置。界面显示当前阶段和截止时间，允许取消，具体配置见[自动连接操作说明](AUTO_CONNECTION.md)。

| 提示 | 下一步 |
| --- | --- |
| 手机连接失败 | 打开云手机，确认开机／网络／ADB，再点击重新检查 |
| 手机已连接，但自动化读取或诊断失败 | 查看诊断详情并重新检查；此提示不表示手机离线 |
| 连续 10 次读取失败或页面无进展 | 查看手机与诊断，在任务中选择“检查并继续”；不需要追加额度 |
| 登录失效、验证码、需要人工处理的页面 | 正常处理后，主动点击处理后检查并继续 |
| 已连接但版本尚未适配 | 查看诊断并进行页面规则适配，不能直接继续 |
| 设备正在使用 | 查看已有运行任务，不反复启动连接服务 |
| 冷却中 | 查看截止时间，不能跳过冷却 |
| 数据库或证据保存失败 | 检查本机存储与诊断；只操作云手机无法解决 |
| 导出失败 | 查看已有任务并重新导出 |

同一问题只提示一次，并在页面保留处理入口。App 在后台时显示 Dock 提示，重开窗口后再处理。打开控制台链接不会清除限制或自动恢复任务。浏览器无法打开时可复制链接。

## 本机安装与维护

App 安装到 `~/Applications/小红书采集助手.app`，桌面同名入口指向它。初版依赖当前项目目录及 `.venv`，不能把 App 单独复制到另一台电脑后直接采集。

开发者在配置完成的项目中构建并安装：

```sh
.venv/bin/python scripts/build_desktop_app.py --install
```

此过程编译原生界面、生成图标、本机签名并注册桌面入口，同时在设备互斥保护下备份和升级本项目已有转发服务；不把数据库密码、原始数据、证据或虚拟环境装入 App。项目移动后需要重新构建入口并检查连接服务路径。

设备配置支持 `cloud_console_url`，当前 `lab01` 使用上面的 HTTPS 控制台地址。私有 ADB 连接与数据库凭据仍由本机配置提供，不显示在普通界面中。

原生界面的启动日志在 `~/Library/Logs/XHSMobileDesktop/desktop-stderr.log`，方便在项目尚未获得访问许可时仍能给出提示；连接、采集和导出的详细日志继续位于项目私有日志目录。界面中的“诊断详情”会打开当前可用的日志位置。

旧终端入口及现有命令行继续可用，见 [终端维护说明](ONE_CLICK.md)。界面验证、synthetic 软件测试和真实采集验收必须分别记录。
